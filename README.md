# MyCalc - Complex Number Calculator

A 100% offline, web-based complex number calculator built with vanilla HTML, CSS, and JavaScript.

## Features

✨ **Completely Offline** - No internet connection required
- Basic Operations: Addition, Subtraction, Multiplication, Division
- Advanced Operations: Conjugate, Magnitude
- Real-time calculations
- Clean, modern UI
- Responsive design (works on desktop and mobile)
- No dependencies required

## Getting Started

1. Open `index.html` in your web browser
2. Start calculating!

## Operations

### Basic Arithmetic
- **Add**: Adds two complex numbers
- **Subtract**: Subtracts the second number from the first
- **Multiply**: Multiplies two complex numbers
- **Divide**: Divides the first number by the second

### Advanced Operations
- **Conjugate**: Finds the conjugate of a complex number
- **Magnitude**: Calculates the absolute value

## Example

To add `3 + 4i` and `1 + 2i`:
1. Enter `3` in Number 1 (Real part)
2. Enter `4` in Number 1 (Imaginary part)
3. Enter `1` in Number 2 (Real part)
4. Enter `2` in Number 2 (Imaginary part)
5. Click "Add"
6. Result: `4 + 6i`

## Complex Number Basics

A complex number is written as **a + bi**, where:
- **a** is the real part
- **b** is the imaginary part (coefficient of i)
- **i** is the imaginary unit (√-1)
